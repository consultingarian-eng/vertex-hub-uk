# Security policy

## Reporting a vulnerability

Please report security problems **privately**, using GitHub's private vulnerability reporting for this repository:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what an attacker could do with it.

**Never open a public issue, pull request or discussion for a vulnerability**, and don't post details anywhere public until a fix is available. Public reports put every office running a copy of this app at risk.

We'll acknowledge your report, keep you updated while we look into it, and credit you in the fix if you'd like.

## Scope

In scope: the code in this repository (the FastAPI backend, the Expo web app, the Dockerfile and CI configuration, the Claude Code skills).

Out of scope:

- Individual deployments run by other people. Each office owner runs their own copy on their own hosting; report problems with a specific site to its owner.
- Third-party services the app talks to (OwnerIQ, MongoDB Atlas, Railway, SendGrid, Anthropic, Cloudflare, Replicate). Report those to the provider.

## If you run a copy of this app

- **Secrets live only in your host's variables** (e.g. Railway → Variables) and in a local `backend/.env` that git ignores. Never commit them, paste them into an issue or chat, or put them in a screenshot.
- This repository contains **no** keys, passwords or connection strings. If you ever find one in it, report it as above.
- **If a secret leaks**, rotate it at the provider straight away (database user password, `JWT_SECRET`, SendGrid, Anthropic, OwnerIQ, storage keys, VAPID keys), update your host's variables and redeploy. Changing `JWT_SECRET` logs everyone out, which is what you want after a leak.
- Keep `COOKIE_SECURE` on in production, `TRUST_PROXY_HEADERS=true` only behind a proxy you trust (Railway), and `OWNERIQ_WRITES_ENABLED` off until you've checked the dry run. With `TRUST_PROXY_HEADERS` on, the app reads the visitor's address from the **right-most** `X-Forwarded-For` entry (the one your proxy appends); set `TRUSTED_PROXY_HOPS` if more than one proxy you control sits in front.
- The no-login pages are protected only by a code, link or password, each with a minimum length and a limit on wrong guesses: the public Bells page by the office's share code (generated by the app; 16+ characters if typed), `/public/roster/<token>` by `ROSTER_SHARE_TOKEN` (32+ characters, or the page stays off), and `/api/manual-editor` by `MANUAL_EDITOR_PASSWORD` (16+ characters, or shared access stays off). Change them if they're shared too widely.
- Set a monthly spend limit on your Anthropic key. The app also caps each person's AI requests per hour (`AI_HOURLY_LIMIT_PER_USER`, default 60).
- `ADMIN_PASSWORD` only creates the owner account. Change the owner password in the app; `ADMIN_PASSWORD_RESET=true` is a one-off recovery switch to remove straight after use ([docs/SETUP.md](docs/SETUP.md#locked-out-of-the-owner-account)).

## Rules the code keeps (for contributors)

- **Ids authorise, names don't.** Anyone can change their display name, so access is decided by stable ids: the OwnerIQ id link (`users.owneriq_user_id`, badge numbers, KPI rows), `trainee_user_id`, `leader_user_id`, `reports_to`. A name may be shown or used to suggest a link, never to grant access.
- **Office admins stay in their office.** Any route that takes another person's, agenda's or record's id checks its `office_id` against the caller's unless the caller is the super-admin.
- **Ids that go into an OwnerIQ URL are digits only**, and every OwnerIQ write checks `OWNERIQ_WRITES_ENABLED` inside `backend/owneriq_write.py`.
- **Files and links that open on the app's own address are pinned:** coaching uploads must be real PDFs and are always served as `application/pdf`; links must be `https://`.
- **Error responses don't carry internal details.** Log the exception on the server and return a short message.
- Pull updates from upstream regularly; security fixes arrive that way ([docs/SETUP.md](docs/SETUP.md#updating-from-upstream)).
